# Gameplay

## Dados
Al jugador se le dan las siguientes opciones de visualizar las tiradas:

- Ver todas las tiradas de dados.
- Ver solo las tiradas de acierto.
- Ver solo las tiradas de daño.
- Ocultar todas las tiradas.

## Reacciones
### Suerte
Al jugador se le dan las siguientes opciones de mostrar el popup de suerte:

- Mostar el popup siempre que tengas la suerte necesaria.
- No mostrar el popup y usar siempre una cantidad de suerte x (establecida por el jugador).
- Solo mostrar el popup cuando la suerte necesaria sea menos de x (establecida por el jugador).
- No mostrar nunca el popup.
